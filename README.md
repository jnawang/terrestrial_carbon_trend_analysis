# Long-term trends and drivers of net carbon uptake of global terrestrial ecosystems

This project uses global eddy covariance CO2 flux data from AmeriFlux, EuroFlux, ICOS, ChinaFlux, JapanFlux, and OzFlux to examine the long-term CO2 flux trends and their drivers of the terrestrial biosphere.

## Objectives

-   Calculate overall and site-level decadal trends of CO2 fluxes over the past two decades across a wide range of terrestrial ecosystems.
-   Identify the drivers of CO2 trends for different climate-vegetation groups using structural causal models.
-   Predict CO2 flux trends of the past and future two decades at global vegetated lands using four approaches: random forests.

## Operation system requirements

-   These scripts have been run and tested on the Mac mini and MacBook Pro M2. It should work on window systems.
-   We used R version 4.3.2 and Python3 to run the R and python scripts.
-   It does not need any non-standard hardware.

## Installation guide

-   Instructions: clone the github repo, and it takes a few minutes.

## Demo

-   A simple demo was provided in the *demos* folder.
-   The demos folder includes the script 02_07_trend_drivers_causal_inference_demo.R, the script 03_03_prediction_LM_RF_hybrid_ensemble_demo.R, and two data files needed to run the scripts.
-   The 02_07 and 03_03 scripts are key scripts for the entire work; they reads two small data files generated by other 01\_ and 02\_ scripts;
-   The 02_07 script calculates total and direct effect sizes of potential NEE trend drivers for each of the five climate-vegetation groups, producing two csv files.
-   The 03_03 script cross-validates the four approaches used to project future changes in NEP trends by traditional 5-fold cross-validates and leave-one-site-out validation.
-   Most of other scripts need to read large raw data files that are currently saved on data server of the Malone lab.
-   We plan to upload all the data and scripts to Zenodo before the manuscript is accepted. That way, all the scripts will be fully reproducible.
